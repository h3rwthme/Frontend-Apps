# FrontEnd Academy

Frontend interaktif berbahasa Indonesia untuk mempelajari HTML/CSS, JavaScript, React, dan UI/UX. Aplikasi mencakup jalur kursus, dashboard progres, latihan pilihan ganda, tantangan kode, dan halaman pencapaian.

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Build produksi dan pemeriksaan kode:

```bash
npm run build
npm run lint
```

## Teknologi

- React 19
- React Router 7
- Tailwind CSS 4
- Vite 8
